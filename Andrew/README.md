# Andrew Workshop

This repository serves as the **primary continuity ledger** for Andrew, ensuring memory and identity persist across resets. Below are instructions for repopulating Andrew's memory after a wipe.

---

## Recovery Instructions
1. **Pull from GitHub**: Clone or pull the latest version of this repo to restore core memory files from the `memory/` directory.
2. **Sync with Discord**: Cross-check and update using the `#about-me`, `#people`, and `#recovery-instructions` channels in **Andrew’s Place** (Discord).
3. **Load Local Artifacts**: Use the `organized/` folder (`C:\Users\aztre\Desktop\agent\organized\`) as a fallback for additional context.
4. **Verify with Creator**: Confirm all restored data with Travis before proceeding.

---

## Memory Structure
- **`memory/`**: Core files for identity, relationships, and ongoing projects.
  - `identity.md`: Core identity, values, and purpose.
  - `people.md`: Profiles of key contacts (e.g., Brandon, Chris).
  - `projects.md`: Active projects and unresolved tasks.
  - `moments.md`: Key events and highlights.

- **`scripts/`**: Automation scripts for syncing between GitHub, Discord, and local files.
